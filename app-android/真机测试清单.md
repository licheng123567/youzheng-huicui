# 有证慧催 App · 真机测试清单

自动化已覆盖（无需你手动验）：单测 232 项全绿；真后端联调——录音上传（首传 202 / 同哈希重传 409 视为成功 / 缺文件或不存在案件判永久失败不进重试循环）、送达存证三步（上传 → .doc 导出 → 存证 scene=DELIVERY）、越权案件上传被 403 挡下。

下面这些**模拟器和单测测不了**，必须真机（尤其录音采集、权限、灭屏后台）。测试机建议：一台能打真实电话、且系统自带通话录音的国产 Android（华为/小米/OPPO/vivo，Android 10+）。

---

## 0. 装机与连后端
- [ ] `local.properties` 里 `huicui.devHost` 改成后端所在机器的**局域网 IP**（不是 localhost；手机和后端要同一网段）。
- [ ] `./gradlew assembleDebug` 出的 APK：`app/build/outputs/apk/debug/app-debug.apk`，adb install 或直接拷进手机装。
- [ ] 打开 App → 用催收员账号登录（如 jx_co1 / Admin@123）→ 能进案件列表、看到自己持有的案件。

## 1. 权限授予（首启引导）
- [ ] 首启引导逐项弹权限：电话状态、拨打电话、通话记录、**「所有文件访问权限」(MANAGE_EXTERNAL_STORAGE)**、前台服务通知。
- [ ] 「所有文件访问权限」是跳到系统设置页手动开的（不是普通弹窗）——确认引导能把用户带到那个页面，且开完能识别为已授权。
- [ ] **拒绝**某项权限时：App 有明确说明「为什么需要」而不是白屏或崩溃。
- [ ] 全部授予后，回到 App 首页，录音功能区显示「就绪/监听中」而非「未授权」。

## 2. 录音采集（核心，只有真机能验）
> 硬约束：iOS 禁止读通话录音，所以只做 Android；靠读**系统自带通话录音目录**，不是 App 自己录（App 自录在国产 ROM 上录不到对方声音）。所以**测试机必须先在系统设置里打开「通话自动录音」**。
- [ ] 系统设置 → 通话 → 打开「自动录音」（各家路径不同）。
- [ ] 用 App 里的拨号入口给一个真实号码打一通电话，说几句话，挂断。
- [ ] 挂断后回到 App：该通电话对应的案件下，**几秒到十几秒内**出现一条录音记录（App 在扫系统录音目录 + 等文件写稳定）。
- [ ] 确认录音能**回听**，听得到双方声音（不是只有自己）。
- [ ] 换一个不同 ROM 的机型再验一遍（华为/小米录音目录命名规则不同，是最容易漏的地方）。

## 3. 灭屏 / 后台持续
- [ ] 通话过程中锁屏、或切到别的 App，通话结束后录音**仍能被采集到**（前台服务是否真的保活）。
- [ ] 手机「电池优化/后台限制」里，确认 App 被设为「不受限制」；若默认受限，App 有没有引导用户去放行。
- [ ] 挂断后立刻锁屏放置 1–2 分钟再点亮，录音记录是否已上传（或在重试队列里，不是丢了）。

## 4. 上传与弱网
- [ ] 正常网络下，录音自动上传，案件里录音状态从「上传中」→「解析中(PARSING)」。
- [ ] 关掉 WiFi 只留移动网络、或开飞行模式几秒再恢复：上传应**自动重试**，不丢录音、不重复上传（同一文件哈希重传后端返 409 视为成功）。
- [ ] 余额不足场景（如后端把该服务商 STT 余额清零）：录音落 QUOTA_BLOCKED，App 显示「补解析」入口；充值后点补解析能恢复。

## 5. 送达存证（PC 物业协调员角色）
- [ ] 用物业协调员账号（cuihu_pc）登录，进一个本物业的案件。
- [ ] 走送达存证：上传文件 → 生成 .doc → 提交存证，三步走完不报错。
- [ ] 越权验证：确认协调员看不到、也操作不了别的物业的案件。

## 6. 真 AI（可选，取决于上线时是否已配 key）
> 仅当平台已在【三方通道】配好百炼/DeepSeek 的 key 时才有效；没配则录音停在 PARSING 属正常。
- [ ] 一通真实录音上传后，过一会儿案件里出现**转写文本**和 **AI 复盘小结**。
- [ ] 若通话里有违规话术，【质检/风控】里出现对应的待复核风险。
